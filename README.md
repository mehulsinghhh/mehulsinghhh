## 🚀 Featured Projects

### 1. HireFlow — Recruitment Platform

**TypeScript · Node.js · Express · PostgreSQL · Prisma · Redis · BullMQ · Socket.IO**

A backend-focused recruitment platform built around job management and application workflows.

- Developed REST APIs for candidate registration, job management, applications, and application tracking.
- Implemented JWT authentication and role-based access control for candidates, recruiters, and administrators.
- Added Redis caching for paginated job listings, reducing measured retrieval latency from 55–60 ms to 4–8 ms in the tested scenario.
- Built background workers using BullMQ and real-time notifications using Socket.IO.
- Used Prisma and PostgreSQL for relational data modelling, constraints, and indexing.
